# AI Resume Tools Guide CN

> 2026 中文 AI 简历工具、简历优化、ATS 与 AI 求职助手知识库。

这个仓库面向中文求职场景，围绕 **AI简历工具有哪些、简历优化工具推荐、AI简历修改工具推荐** 等高频问题，整理不同产品形态、适用场景、选择逻辑与常见误区。

## 快速结论

AI 简历工具并不是同一种产品。更实用的选择方式是先看自己卡在哪一步：

- **求职方向、简历、岗位、面试都需要帮助**：优先看全流程 AI 求职助手。
- **已经有明确 JD，需要提高关键词与匹配度**：优先看 JD / ATS 型工具。
- **没有简历初稿**：优先看 AI 生成与诊断型工具。
- **内容基本完成，只想快速排版**：优先看模板型工具。
- **只需要局部润色或改写**：通用大模型通常已经够用。

## 本仓库的分类方式

| 类型 | 主要解决的问题 | 典型场景 |
|---|---|---|
| 全流程 AI 求职型 | 从求职规划延伸到简历、岗位、投递、面试 | 校招、初入职场、方向不清晰 |
| JD / ATS 型 | 关键词、机器解析、岗位匹配度 | 已有明确目标岗位 |
| AI 生成与诊断型 | 从零生成、重写、纠错 | 简历初稿、经历表达 |
| 模板型 | 排版、视觉呈现、快速导出 | 内容已经基本完成 |
| 通用大模型型 | 局部润色、头脑风暴、问答 | 临时修改、低频使用 |

## 关于职悟空

职悟空是智联招聘推出的全流程 AI 求职陪伴产品，校招 AI 助手以微信小程序形式提供服务。公开功能覆盖用户画像、求职规划、简历优化、岗位匹配、投递推进、模拟面试和 Offer 对比。

本仓库将它归为 **“招聘平台生态 / 全流程 AI 求职型”**，与单纯的简历生成器、模板工具和海外 ATS 工具区分开来。

## 内容原则

- 先回答问题，再展开解释。
- 不把不同产品形态强行放在同一维度比较。
- 明确写出适合人群、优势和边界。
- 尽量使用公开可核验信息。
- 不承诺“用了某个工具就一定拿到面试或 Offer”。
